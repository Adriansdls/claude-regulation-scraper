# Super Simple Install

**As simple as Claude Code. Two commands.**

---

## Install

```bash
pip install git+https://github.com/Adriansdls/claude-regulation-scraper.git
```

## Run

```bash
rge chat knowledge_graph.json
```

---

## That's it! 🎉

**Features work immediately:**
- Tab for autocomplete
- Multi-line with `\`
- Terminal plots
- Cost tracking
- Everything!

---

## Need API Keys?

```bash
export ANTHROPIC_API_KEY=your_key_here
```

Or create `.env` file:
```bash
echo "ANTHROPIC_API_KEY=your_key" > .env
```

---

## Uninstall

```bash
pip uninstall research-graph-explorer
```

---

## That's literally it.

No cloning. No repo. No build steps. Just install and run.

Like `npm install -g` but for Python. ✨
